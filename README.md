# 周期表 暗記アプリ

元素の原子番号・名称・元素記号を覚えるための、ブラウザで動く学習アプリです。インストールは不要で、PC・iPad・スマートフォンで使えます。

## 使い方

- **周期表**：元素をタップすると、存在状態・身近な用途・主な化合物などのカードが開きます。色分け（分類・常温の状態・覚えた度など）と範囲を切り替えられます。
- **カードで覚える**：表を見て答えを思い浮かべ、タップで裏返して「覚えた／まだ」を選びます。
- **4択クイズ**：範囲と形式を選んで解きます。結果は周期表の「覚えた度」に反映されます。
- **中学／高校**：中学を選ぶと、電子配置・原子量・炎色反応など高校の内容を隠します。

学習記録は使っている端末のブラウザの中だけに保存され、外部には送信されません。

## 収録データ

全118元素。人工元素（原子番号104以降）の電子配置などは予測値です。
